PromptForge

Connect this extension to your PromptForge account.

  1. Open PromptForge → Settings → API keys.
  2. Tick “Allow publishing (write access)” — required to save prompts. A read-only key can only search.
  3. Create the key and paste the secret below.

The key is stored with chrome.storage.local on this device and is only ever sent to the URL above.
