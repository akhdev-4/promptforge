# Changelog

## 0.2.0

- **Publish Selection as Prompt** — select text (or use the whole file) and
  publish it to PromptForge as a new prompt, from the Command Palette or the
  editor right-click menu. Requires a write-scoped API key; read-only keys are
  rejected with a clear message.

## 0.1.0

- **Starter Kits** view in the activity bar.
- **Pull Kit into Workspace** — download and unpack a kit's codebase, with a
  generated `PROMPTFORGE.md` listing its prompts.
- **Search Prompts** and insert content into the editor.
- **Set API Key** (stored in SecretStorage), **Who Am I**, **Refresh Kits**.
